About and how to use

This page simulates the short-term interest rate with the Vasicek model: the rate is pulled towards a long-run level θ at speed κ while random shocks of size σ push it around. A bond is valued by discounting its payments along every simulated path and averaging the results (Monte Carlo). The same paths give the bond’s value one year from now, which shows how much could be lost.

Steps

  1. Pick one of the two fitted sets of values, or move the sliders. The chart and the headline value respond at once, using exact formulas.
  2. Press Start. Paths are simulated in batches and every number updates as they arrive.
  3. Pause freezes the run and Start continues it. Reset clears it.
  4. Changing any value clears the run, because its results no longer belong to the new values.

Things you can touch

  • Drag the dashed line on the main chart to change the long-run rate θ, or the dot at the left edge to change the starting rate.
  • Hover over any chart to read exact values at that point.
  • Use the button at the top right to switch between the white and the dark colour scheme.

Try this

Run Calm period: the bond is worth about 103 and the Value-at-Risk is negative, so the holder gains even in a bad year. Then run Full history incl. 2022 crisis: the value falls to about 95 and the Value-at-Risk becomes a real loss of about 6. The bond has not changed. Only the assumed behaviour of interest rates has.

Reading the outputs

  • Values are in LKR per 100 of face value. The ± figure is a 95% confidence interval and narrows as paths are added.
  • Exact formula is the known closed-form Vasicek price of a zero-coupon bond. The simulated price should land close to it.
  • Value-at-Risk is the one-year loss exceeded in only 5% of scenarios, measured against today’s value and counting coupons received. Negative means a gain.
  • Expected Shortfall is the average loss within that worst 5%.

Agreement with the notebook

With the Calm period values and at least 50,000 paths, the simulated zero-coupon price must agree with the notebook’s reference result of within LKR. The status line under the figures reports whether it does.

Limitations

  • The three model settings stay constant for five years, so the model cannot switch between calm and crisis behaviour.
  • Shocks are normally distributed. Real rates sometimes jump.
  • No extra return for bearing interest-rate risk is included, so model values sit above market prices.
  • The Vasicek model allows negative rates when volatility is high.
  • The one-year revaluation uses the exact Vasicek formula, while the notebook uses a simulated grid. The two agree within 0.05 LKR.
  • Default risk, taxes and trading costs are ignored. This is a teaching tool and not investment advice.

Rate data behind the fitted values: Central Bank of Sri Lanka, “Rates on Government Securities”.
